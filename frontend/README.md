# Frontend

This folder will hold the FraudShield merchant-facing web application.

**Status:** Not yet implemented — Phase 1 architecture and design stage only.

## Planned Stack
- React.js
- Tailwind CSS
- Recharts / Chart.js for the fraud analytics dashboard
- WebSocket client for real-time alert delivery

## Planned Scope
- Merchant authentication screens
- Real-time transaction / alert feed
- Risk score + explainability panel (contributing risk factors per transaction)
- Approve / Review / Verify / Block action controls
- Fraud analytics dashboard (volume, flagged transactions, risk distribution, trends)
- Merchant feedback controls ("Fraud" / "Legitimate" / "Reviewed")

See the [Phase 1 Proposal](../docs/Phase1_Proposal.pdf) for the full product design.
